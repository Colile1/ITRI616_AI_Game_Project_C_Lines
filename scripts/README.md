# scripts/

Standalone utility scripts for evaluation demos and figure generation.

| File | Purpose |
|------|---------|
| `demo_eval.py` | Run a head-to-head evaluation between two named snapshots and print results |
| `make_report_figures.py` | Regenerate all training figures for all runs |

```powershell
python scripts/demo_eval.py
python scripts/make_report_figures.py
```
